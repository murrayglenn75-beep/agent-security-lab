# Validation

## v1.0 release gates

The repository is intended to pass:

```bash
pytest
ruff check .
mypy src
python scripts/public_release_scan.py
python -m pip check
asl suite
```

These values describe only the included deterministic corpus and should be regenerated from the current code before a release.

## Evidence discipline

Do not publish a benchmark number that was not generated by a real suite run. Generated `reports/` files are intentionally ignored so reviewers can reproduce results locally.
